## Features

- **Multiple highlight colors** — Yellow, green, blue, pink, orange
- **Multiple styles** — Highlight, underline, strikethrough
- **Add notes** — Attach notes to any annotation
- **Persistent** — Annotations survive page reloads and browser restarts
- **Quick toolbar** — Select text → instant annotation toolbar
- **Floating button** — Draggable FAB for quick access to all tools
- **Annotation manager** — View, search, and organize all your annotations
- **Export / Import** — Backup and restore your annotations as JSON
- **Multi-language** — English & 中文
- **Privacy-first** — All data stays on your device, zero tracking

## Installation

### Option 1: Edge Add-ons (Recommended)

> Coming soon — under review.

### Option 2: Chrome / Edge Manual Install

1. Go to the [Releases](https://github.com/lemoabc/WebMarker-releases/releases) page
2. Download the latest `webmarker-vX.X.X.zip` file
3. Unzip the downloaded file
4. Open your browser and navigate to:
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
5. Enable **"Developer mode"** (toggle in the top-right corner)
6. Click **"Load unpacked"**
7. Select the unzipped folder
8. Done! You'll see the Web Marker icon in your toolbar.

### Updating

To update to a new version:
1. Download the latest release zip
2. Unzip and replace the old folder
3. Go to `chrome://extensions/` → click the refresh icon on Web Marker

## How to Use

1. **Select text** on any webpage — a mini toolbar appears
2. **Choose a color** or style to annotate
3. **Click the floating button** (bottom-right) to access all tools
4. **Manage annotations** via the popup (click extension icon) or the full management page

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Esc` | Deactivate current tool / collapse panel |
| Right-click FAB | Quick activate last-used tool |
| Drag FAB | Move the floating button anywhere |
