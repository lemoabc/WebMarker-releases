## 功能特性

- **多种高亮颜色** — 黄、绿、蓝、粉、橙
- **多种标注样式** — 高亮、下划线、删除线
- **添加笔记** — 为任何标注附加备注
- **持久保存** — 标注在页面刷新和浏览器重启后依然保留
- **快捷工具栏** — 选中文字 → 即刻弹出标注工具
- **悬浮按钮** — 可拖动的 FAB 按钮，快速访问所有工具
- **标注管理** — 查看、搜索、整理你的所有标注
- **导入 / 导出** — 以 JSON 格式备份和恢复标注数据
- **中英双语** — 支持英文和中文界面
- **隐私优先** — 所有数据留在本地，零追踪

## 安装方式

### 方式一：Edge 扩展商店（推荐）

[![Edge 扩展商店](https://img.shields.io/badge/Edge%20%E6%89%A9%E5%B1%95%E5%95%86%E5%BA%97-%E7%AB%8B%E5%8D%B3%E5%AE%89%E8%A3%85-0078D7?logo=microsoftedge&logoColor=white)](https://microsoftedge.microsoft.com/addons/detail/jjopjgjjgiodkebohhkaohflmelahpnd)

从 [Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/jjopjgjjgiodkebohhkaohflmelahpnd) 一键安装，自动更新。

### 方式二：Chrome / Edge 手动安装

1. 前往 [Releases](https://github.com/lemoabc/WebMarker-releases/releases) 页面
2. 下载最新的 `webmarker-vX.X.X.zip` 文件
3. 解压下载的 zip 文件
4. 打开浏览器，访问：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
5. 开启右上角 **"开发者模式"**
6. 点击 **"加载已解压的扩展程序"**
7. 选择解压后的文件夹
8. 完成！你会在工具栏看到 Web Marker 图标。

### 更新方法

1. 下载最新版本的 zip 文件
2. 解压并替换旧文件夹
3. 前往 `chrome://extensions/` → 点击 Web Marker 上的刷新图标

## 使用方法

1. **选中文字** — 在任意网页上选择一段文字，迷你工具栏会自动弹出
2. **选择颜色或样式** — 点击对应按钮完成标注
3. **点击悬浮按钮**（右下角）— 展开查看所有工具
4. **管理标注** — 通过扩展弹窗（点击工具栏图标）或标注管理全页面

### 快捷操作

| 操作 | 说明 |
|------|------|
| `Esc` | 取消当前工具 / 折叠面板 |
| 右键点击 FAB | 快速激活上次使用的工具 |
| 拖拽 FAB | 将悬浮按钮移动到任意位置 |
